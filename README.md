# Build Guild

One-page site for Build Guild — designers and engineers building small, open source tools for nonprofits.

Plain HTML, CSS, and a little JavaScript. No build step: open `index.html` in a browser.

- `index.html` — page content
- `styles.css` — layout, colors, type, and the spheres
- `script.js` — parallax, sphere wander, word-by-word reveal, and the dark scroll scene
- `assets/` — project card images

Design source: Figma file "Build Guild — Landing Page", page "Option B — Simple".
